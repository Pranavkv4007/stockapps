# CLAUDE.md — Visualizations (Score Dashboards)

Two Streamlit visualization apps that read the output data generated by the FullScreener and individual stock analysis pipelines.

## Commands

```bash
# Launch Sector Score Visualizer
launch.bat
# Or: streamlit run Visualizations\ScoreVisualApp.py

# Launch Individual Stock Score Visualizer
Individual.bat
# Or: streamlit run Visualizations\Individualscoreapp.py
```

## Apps

### 1. ScoreVisualApp.py — Sector Score Visualizer

Reads sector CSVs from `Sector/` and provides interactive exploration.

**Data Loading:**
- `run_csv_combiner()` — replicates CsvCombiner.ipynb: reads all CSVs in `Sector/*/`, filters top scores using `floor(max/10)*10` threshold, saves `Sector_Combined.csv`
- `load_all_sectors()` — loads ALL companies from all sector CSVs (unfiltered)

**Tabs:**
- **Overview** — Sector summary table (avg score, top score, company count), Top N filter
- **Sector Analysis** — Drill into a sector, score range slider, horizontal bar chart (Plotly), pie chart for tier breakdown
- **Company Leaderboard** — Overall top N across all sectors + per-sector leaderboard cards (2-column grid)
- **Raw Data** — Full dataset table + download buttons (Filtered CSV, Combined CSV)

**Sidebar:** Sector checkboxes with Select All, Top N slider, Refresh Data button

### 2. Individualscoreapp.py — Individual Stock Score Visualizer

Reads `.txt` files from `Individual_Stocks/` and extracts/combines scores.

**Data Loading:**
- `extract_overall_score(file_path)` — 4-pass regex extraction from `{Company}.txt` files
- `extract_credibility_score(file_path)` — 3-pattern regex extraction from `{Company}_concall_score.txt`
- Combined score = average of both (where both exist)
- Saves `scores.json` with `{ overall_scores, credibility_scores }`

**Tabs:**
- **Overview** — Top N table with Rank, Company, Financial/Concall/Combined Score, Tier, Signal; tier summary
- **Score Comparison** — Aligned stocks (gap <= 10), Divergent stocks (gap > 10), Full comparison table
- **Leaderboard** — Top N by selected score type + companies missing scores
- **Raw Data** — Full dataset + CSV/JSON downloads

**Signal Classification:**
- Strong Buy: both >= 75
- Moderate Buy: both >= 60
- Mixed: scores disagree
- Avoid: both < 50
- Grey labels for missing scores

**Tier Assignment:** Excellent (80+), Good (60+), Average (40+), Weak (<40)

**Score Colors:** `#2d6a4f` (excellent), `#52b788` (good), `#f4a261` (average), `#e76f51` (weak)

## Critical: Do NOT Change

- Regex patterns in `extract_overall_score` and `extract_credibility_score` — tuned for inconsistent LLM output
- `floor(max/10)*10` filtering logic in `run_csv_combiner`
- Signal classification thresholds
- `scores.json` always overwrites (never appends)
- `Sector_Combined.csv` always overwrites (never appends)
