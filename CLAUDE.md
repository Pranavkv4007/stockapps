# CLAUDE.md — Stock Analysis Apps (Root)

This is a monorepo of stock analysis tools for the Indian stock market. It contains multiple apps that scrape financial data from Screener.in, run LLM-powered analysis pipelines, and visualize results.

## Project Structure

```
Apps_link/
├── Full App/          # Unified FastAPI + HTML frontend (combines all other apps)
├── FullScreener/      # Streamlit app — sector-level screener pipeline
├── individual/        # Streamlit app — individual stock analysis pipeline
├── Visualizations/    # Streamlit apps — score visualization dashboards
├── Individual_Stocks/ # Output data — per-company analysis .txt files
├── Sector/            # Output data — per-sector folders with .txt, .csv, .json files
├── scores.json        # Aggregated individual stock scores (auto-generated)
├── .env               # API keys: OPENAI_API_KEY, GOOGLE_API_KEY
├── .venv/             # Python virtual environment
└── requirements.txt   # Python dependencies
```

## App Relationships

1. **FullScreener** → Scrapes Screener.in sector pages → LLM extracts financials → LLM scores companies → Saves to `Sector/{sector_name}/`
2. **individual** → Scrapes a single company page → 8-step LLM pipeline → Saves to `Individual_Stocks/`
3. **Visualizations** → Reads output from the above two → Displays interactive dashboards
4. **Full App** → Unified FastAPI backend + HTML frontend that combines ALL of the above into one app, including running pipelines via API

## Shared Data

- `Sector/` — Each sub-folder is a sector name containing `.txt` (financial data), `_Score.txt` (analysis), `.csv` (scores), `.json` (structured)
- `Individual_Stocks/` — `{Company}.txt` (financial analysis), `{Company}_concall.txt` (walk the talk), `{Company}_concall_score.txt` (credibility score)
- `scores.json` — `{ "overall_scores": {...}, "credibility_scores": {...} }` auto-generated by visualization apps

## Environment

- Python 3.12, venv at `.venv/`
- API keys in `.env`: `OPENAI_API_KEY`, `GOOGLE_API_KEY`
- Windows-only `.bat` launchers per app
- Key packages: streamlit, fastapi, openai, google-genai, pandas, plotly, beautifulsoup4

## LLM Models Used

- `gpt-4.1-mini-2025-04-14` (OpenAI)
- `gpt-4o-mini-2024-07-18` (GPT-4o)
- `gemini-3-pro-preview` (Google Gemini)

## Critical Rules

- **Do NOT simplify regex patterns** in score extraction functions — they are tuned for inconsistent LLM output
- **Do NOT change the floor-based filtering** in CSV combiner (`floor(max/10)*10`)
- **Signal classification and tier assignment** logic must match exactly across all apps
- Data scraping targets `screener.in` — all URL parsing and link extraction assumes this site's structure
