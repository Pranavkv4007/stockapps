# CLAUDE.md — Individual_Stocks (Data Directory)

This is an **output data directory**, not an app. It contains LLM-generated analysis files produced by the `individual` app pipeline and read by the `Visualizations` and `Full App` apps.

## File Naming Convention

For each analyzed company, there are 3 files:

| File Pattern | Content | Generated By |
|---|---|---|
| `{Company}.txt` | Final comprehensive financial analysis with overall score (0-100) | Pipeline Step 5 |
| `{Company}_concall.txt` | "Walk the Talk" analysis — management guidance vs actual outcomes | Pipeline Step 6 |
| `{Company}_concall_score.txt` | Concall credibility score analysis | Pipeline Step 7 |

## Score Extraction

The visualization apps extract scores from these files using regex:

- **Overall score** from `{Company}.txt`: looks for "Overall Score: X/100", JSON "score": X, table rows
- **Credibility score** from `{Company}_concall_score.txt`: looks for "Credibility Score: X/100", table formats

## Important

- File names use the company's full name as shown on Screener.in (including "Ltd")
- Files without underscores in the stem = financial analysis files
- Files ending in `_concall.txt` = walk the talk analysis
- Files ending in `_concall_score.txt` = credibility scoring
- Do NOT manually edit these files — they are regenerated by the pipeline
