### 4.3 Score Extraction Logic — MUST BE EXACT

#### Overall Score Extraction (from `extract_overall_score`)
The function parses `.txt` files using 4 fallback passes:
1. Lines containing "overall score" or "overall financial health score" → regex `(\d+)\s*/\s*100`
2. First 30 lines: JSON-style `"score": 85` or `"Overall Score": 80` → value 0-100
3. Table row: `overall composite score` → `**(\d+)**`
4. Table row: `| **Total** | ... | **78** |` → value 1-100

#### Credibility Score Extraction (from `extract_credibility_score`)
Parses `*_concall_score.txt` files using 3 regex patterns:
1. `credibility score: 55 / 100` format
2. `credibility score: 55` (no denominator)
3. Table pipe format `| **55 (Moderate)**`

**⚠️ CRITICAL**: These regex patterns must be copied EXACTLY from the original code. Do not simplify or "improve" them — the LLM output formats they parse are inconsistent and these patterns were tuned for real data.

### 4.4 Signal Classification (from `assign_signal`)

```
Both scores >= 75           → "Strong Buy"
Fin >= 75, Con < 60         → "Financials Strong, Concall Weak"
Con >= 75, Fin < 60         → "Concall Strong, Financials Weak"
Both >= 60                  → "Moderate Buy"
Both < 50                   → "Avoid"
Otherwise (both exist)      → "Mixed"
Only Financial exists       → "Concall Missing"
Only Concall exists         → "Financials Missing"
```

### 4.5 Tier Assignment

```
Score >= 80  → "Excellent"
Score >= 60  → "Good"
Score >= 40  → "Average"
Score <  40  → "Weak"
```

## 9. RUN INSTRUCTIONS

### One-Command Launch

Create `run.sh` and `run.bat` that:
1. Install Python dependencies (`pip install -r requirements.txt`)
2. Start the FastAPI backend on `http://localhost:8000`
3. Serve the frontend on `http://localhost:3000` (or via FastAPI static files on the same port)
4. Open the browser automatically

```bash
# run.sh
#!/bin/bash
cd backend
pip install -r requirements.txt --quiet
uvicorn main:app --host 0.0.0.0 --port 8000 &
echo "🚀 Stock Analysis Hub running at http://localhost:8000"
open http://localhost:8000  # macOS; use xdg-open on Linux
```

### Simpler Alternative
If using FastAPI to serve both API and static frontend files, only one server process is needed. **This is the preferred approach** — mount the frontend as static files in FastAPI:

```python
from fastapi.staticfiles import StaticFiles
app.mount("/", StaticFiles(directory="../frontend", html=True), name="frontend")
```
