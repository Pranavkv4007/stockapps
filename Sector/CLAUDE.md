# CLAUDE.md — Sector (Data Directory)

This is an **output data directory**, not an app. It contains LLM-generated analysis files produced by the `FullScreener` sector pipeline and read by the `Visualizations` and `Full App` apps.

## Directory Structure

```
Sector/
├── {Sector Name}/              # One folder per analyzed sector
│   ├── {Company}.txt           # Extracted financial data from screener.in
│   ├── {Company}_Score.txt     # LLM-generated score analysis
│   ├── {Sector Name}.json      # Array of {company, score, key_metrics, explanation}
│   ├── {Sector Name}.csv       # Columns: company, score, Sector, url
│   └── progress.json           # Resumable progress tracker for JSON creation phase
└── Sector_Combined.csv         # Auto-generated: top-scoring companies across all sectors
```

## Current Sectors

- `Capital Markets Companies/`
- `Stockbroking & Allied Companies/`

Each folder contains ~30-40 company `.txt` and `_Score.txt` files.

## CSV Format

Sector CSVs have columns: `company`, `score`, `Sector`, `url`

`Sector_Combined.csv` is auto-generated by `run_csv_combiner()` which:
1. Reads all CSVs in sector sub-folders
2. For each CSV, sorts by score descending
3. Keeps companies scoring >= `floor(max_score / 10) * 10`
4. Concatenates and saves (always overwrites, never appends)

## Important

- Folder names match the sector title from Screener.in (may contain special characters like `&`)
- `.txt` files without `_Score` suffix = raw financial data extraction
- `_Score.txt` files = LLM analysis with score
- Files are cached — the pipeline skips companies with existing files
- Do NOT manually edit these files — they are regenerated by the pipeline
